# Olimpo - E-commerce de Streetwear

Um e-commerce responsivo desenvolvido em React, especializado em produtos de streetwear com foco na cultura pernambucana.

[Ver projeto ao vivo](https://olimpo-andrevss.vercel.app)

## Funcionalidades

- Catálogo de produtos com visualização de frente e verso
- Sistema de carrinho com persistência
- Seleção de tamanhos com indicação de disponibilidade
- Design responsivo para mobile e desktop
- Carousel de banners promocionais
- Integração com WhatsApp para finalização de pedidos

## Tecnologias

- **React** + **React Router**
- **Tailwind CSS**
- **Context API**
- **React Multi Carousel** / **React Icons**

## Como Executar

```bash
git clone https://github.com/Andrevss/Olimpo.git
cd Olimpo/frontend
npm install
npm start
```

Acesse [http://localhost:3000](http://localhost:3000)
